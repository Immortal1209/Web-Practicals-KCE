# KCE Web Development Practicals

## About the Repository
This repository contains HTML programs completed as part of Web Development practicals. It covers the fundamentals of HTML, including webpage structure, hyperlinks, tables, and forms.

## Practical List

### Practical 1: Basic HTML
**File:** `practical1.html`

**Topics Covered:**
- Basic HTML document structure
- Headings and paragraphs
- Bold text formatting
- Line breaks
- Unordered lists
- Ordered lists

**Objective:** To understand the basic structure of an HTML document and learn how to display text and lists on a webpage.

### Practical 2: Hyperlinks
**File:** `practical2.html`

**Topics Covered:**
- Internal hyperlinks
- External hyperlinks
- Image hyperlinks
- Email links using `mailto:`
- Links to other HTML pages
- Using the `href` attribute
- Using the `id` attribute for internal navigation

**Objective:** To learn how to connect webpages and navigate between different sections and external websites.

### Practical 3: HTML Tables
**File:** `practical3.html`

**Topics Covered:**
- Creating tables using `<table>`
- Table rows using `<tr>`
- Table headings using `<th>`
- Table data using `<td>`
- Table borders
- Using `colspan`
- Aligning tables

**Objective:** To organize and display student information in tabular form.

### Practical 4: HTML Forms
**File:** `practical4.html`

**Topics Covered:**
- Creating forms using `<form>`
- Text input fields
- Email input fields
- Password input fields
- Radio buttons
- Checkboxes
- Dropdown lists using `<select>` and `<option>`
- Submit buttons
- Reset buttons

**Objective:** To create a student registration form and understand different HTML form controls.

## Technologies and Tools
- **HTML5:** For structuring webpages
- **Visual Studio Code:** For writing and editing HTML code
- **Web Browser:** For displaying and testing the output
- **Git and GitHub:** For version control and storing practical files (if used)

## How to Run the Practicals
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required `.html` file.
4. Run the file in a web browser.
5. Observe and test the output.

## Learning Outcomes
After completing these practicals, students will understand:
- The basic structure of HTML documents.
- How to format text and create lists.
- How to create and navigate hyperlinks.
- How to organize information using tables.
- How to collect information using HTML forms.
